# 📦 Supply Chain & Logistics Analytics Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing supply chain and logistics operations using **Microsoft Power BI**. The dashboard provides insights into revenue, profitability, inventory, shipments, delivery performance, and supplier efficiency to support data-driven business decisions.

By transforming operational data into meaningful KPIs and interactive visualizations, this project helps identify performance trends, monitor logistics operations, and understand potential areas for improvement across the supply chain.

## 🎯 Business Objectives

- Monitor overall revenue, profit, and profit margin.
- Analyze inventory quantity and inventory value.
- Track orders, shipments, and delivered quantities.
- Evaluate shipment delays and delivery performance.
- Analyze supplier lead times and carrier performance.
- Monitor perfect order percentage to understand order fulfillment quality.
- Support business stakeholders with KPI-driven reporting and insights.

## 📊 Key Performance Indicators (KPIs)

| KPI | Purpose |
|---|---|
| Total Revenue | Measures overall sales revenue |
| Profit | Evaluates financial performance |
| Profit Margin % | Measures profitability relative to revenue |
| Inventory Value | Tracks the monetary value of inventory |
| Inventory Quantity | Monitors available inventory |
| Total Shipments | Measures shipment volume |
| Shipment Quantity | Tracks the quantity shipped |
| Order Quantity | Measures order volume |
| Delivered Quantity | Tracks fulfilled quantities |
| Average Lead Time | Evaluates supplier delivery efficiency |
| Total Delay | Helps monitor shipment delays |
| Perfect Order % | Measures order fulfillment performance |

## 🗂️ Data Model

The project uses a structured data model with fact and dimension tables, including:

- `fact_sales` — Sales and revenue-related data
- `fact_shipment` — Shipment and carrier-related data
- `dim_customer` — Customer information
- `dim_product` — Product information
- `dim_supplier` — Supplier information
- `Measure_table` — Measures used to calculate business KPIs

This structure supports analysis across customers, products, suppliers, sales, and shipment operations.

## 💡 Business Value

This dashboard demonstrates how Power BI can turn supply chain data into actionable business intelligence. It provides a consolidated view of financial and operational performance, helping stakeholders monitor key metrics, investigate delivery issues, and evaluate supplier and fulfillment efficiency.
